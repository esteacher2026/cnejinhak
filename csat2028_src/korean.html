학습 방향

2028 수능 국어는 선택과목을 고르는 시험이 아니라, 세 과목의 능력을 통합적으로 요구하는 시험입니다. 화법의 상황 판단, 언어의 자료 탐구, 독서의 구조 독해, 작문의 조건 처리, 문학의 근거 있는 감상을 모두 관리해야 합니다.

1. 2028 SYSTEM

2028 수능 국어 체제

국어 영역은 2022 개정 국어과 교육과정의 화법과 언어, 독서와 작문, 문학을 중심으로 다양한 소재의 지문과 자료를 활용해 국어 능력을 평가합니다.

항목2028 수능 국어학생이 알아야 할 의미
출제과목화법과 언어, 독서와 작문, 문학선택과목 유불리를 기대할 수 없고, 세 과목을 모두 준비해야 한다.
문항 수·시간45문항, 80분영역별 독해력뿐 아니라 시간 배분과 보류 기준이 점수에 직접 연결된다.
문항 유형5지선다형서술형 답안 작성은 없지만, 작문·비평·자료 활용 과정이 객관식으로 평가된다.
평가 방식상대평가표준점수, 백분위, 등급이 제공되므로 한두 문항 차이가 중요하다.
EBS 연계간접 연계 50% 유지지문 암기보다 소재·주제·자료·작품 읽는 방식의 전이가 중요하다.
핵심 결론

2028 수능 국어의 핵심은 “어떤 선택과목을 고를까”가 아니라 “낯선 자료와 지문을 어떤 절차로 읽고, 어떤 근거로 선지를 판정할까”입니다.

2. ASSESSMENT GOALS

평가 목표와 행동 영역: 무엇을 훈련해야 하는가?

2028 수능 국어는 내용 영역과 행동 영역을 함께 봅니다. 과목명만 외우는 것이 아니라, 각 과목이 어떤 행동을 요구하는지 알아야 합니다.

내용 영역별 평가 목표

내용 영역평가하는 능력학습 행동
화법다양한 담화 상황에 맞게 발화 내용을 생성·조직·표현하고, 청중 반응을 고려해 조정하는 능력화자·청자·목적·상황·자료·반응을 먼저 표시한다.
언어언어의 본질, 단위 체계, 국어의 역사와 자료 탐구를 바탕으로 국어의 특징을 파악하는 능력문법 개념을 정의→조건→예문→예외 순서로 적용한다.
독서다양한 글을 사실적·추론적·비판적으로 이해하고 새로운 상황에 적용하는 능력문단 역할, 개념 관계, 관점, 조건, 사례 적용을 구조화한다.
작문작문 상황에 맞게 내용을 생성·조직·표현하고 예상 독자의 반응을 고려해 점검·조정하는 능력독자·목적·장르·자료 활용·고쳐쓰기 기준을 문제 조건으로 처리한다.
문학문학 작품을 사실적·추론적·비판적·창의적으로 수용하고 재구성하는 능력작품 내적 근거와 외적 관점을 구분해 감상한다.

행동 영역별 훈련법

행동 영역시험장에서 요구되는 행동훈련 루틴
어휘·개념정확하고 효과적인 어휘 사용, 과목별 기본 개념 이해핵심어를 쉬운 말로 바꾸고, 개념의 적용 조건을 적는다.
사실적 이해정보의 정확한 파악, 정보 간 관계와 구조 파악선지 근거를 지문·자료에서 직접 찾는다.
추론적 이해명시되지 않은 의미, 전제, 논거, 필자 의도 추론직접 제시된 것과 추론한 것을 구분해서 표시한다.
비판적 이해내용의 타당성·적절성·가치 평가, 문학 작품의 비판적 감상관점, 근거, 한계, 반론 가능성을 표로 정리한다.
적용·창의개념과 원리를 새로운 맥락에 적용, 말과 글의 생성·조직·표현·수정<보기> 자료가 지문의 어느 개념과 연결되는지 먼저 찾는다.
3. FIRST ACTION

영역별 첫 행동 프로토콜

2028 수능 국어는 과목별로 지문을 읽는 첫 행동이 달라야 합니다. 첫 행동이 고정되면 시간 손실과 오답률이 줄어듭니다.

화법과 언어담화 + 언어 자료

첫 행동
1. 화자·청자·목적·상황 확인
2. 자료가 담화에서 맡는 역할 표시
3. 발화 태도와 청중 반응 확인
4. 어휘·문법 요소의 기능 분석
5. 선지가 상황에 적절한지 판단

대표 함정: 발표 목적과 맞지 않는 자료 활용, 청중 반응 오독, 문법 요소의 기능 착각.

독서와 작문읽고 쓰는 능력

첫 행동
1. 화제와 핵심 개념 확인
2. 문단 역할 표시
3. 관점·근거·예시·한계 구분
4. 추가 자료의 기능 확인
5. 작문 목적·독자·고쳐쓰기 조건 판정

대표 함정: 세부 사례를 중심 주장으로 착각, 자료의 신뢰성·활용 목적 누락, 반론·반박 방향 오류.

문학작품 + 관점 자료

첫 행동
1. 갈래와 화자/서술자 확인
2. 상황·정서·태도 정리
3. 핵심 소재와 표현 효과 표시
4. 보기 자료의 관점 파악
5. 작품 근거와 외적 관점의 연결 검증

대표 함정: 기존 해석 의존, 정서 과장, 관점 자료를 작품 구절과 연결하지 못함.

무엇을 묻나 · 디지털 영화의 리얼리즘(영화-눈·영화-붓·지각적 리얼리즘) 개념을 읽고, 감독 인터뷰라는 추가 자료를 연결해 비평문에 넣을 내용을 판단합니다.

교수·학습 주안점 · 사실적·추론적 이해로 글에 나타난 관점들을 비교·분석해 정리하고, 글의 정보와 사례의 연결 지점을 파악합니다. 읽은 글로 글을 쓰며 생성한 내용이 지문과 논리적 정합성이 있는지 점검합니다.

교수·학습 주안점 · 여러 글의 정보를 비교·대조하고 자료의 신뢰성·타당성을 평가하며 읽습니다. 유사한 화제의 여러 글을 비판적으로 읽고 자신의 관점과 입장을 형성하는 능동적 읽기를 연습합니다.

27번 · 작문 · 비판적 이해 · [12독작01-06]·[12독작01-11]

논증하는 글의 초고 보강(고쳐쓰기)

교수·학습 주안점 · 주장·이유·근거·예상 반론·반박이라는 논증 요소를 이해하고, 근거 자료의 타당성·신뢰성을 점검합니다. 예상 반론에 대한 반박 내용을 구상하고 이를 뒷받침할 자료를 탐색하는 연습을 합니다.

문학

42번 · 문학 · 비판적 이해 · [12문학01-07]·[12문학01-11]

작품 속 공동체 문제와 해결 과정의 비판적 감상

무엇을 묻나 · <학습 활동> 자료가 견지하는 관점(생태주의의 문제의식을 사회적 차원으로 확장)을 파악하고, 이를 소설 속 인물의 말·행동과 연결해 공동체 문제 해결 과정을 비판적으로 감상합니다.

교수·학습 주안점 · 자료를 바탕으로 인물의 말·행동의 의미, 사건 전개, 서술자의 태도를 파악합니다. 생태적 위기·사회적 불평등 등 공동체 문제를 다룬 작품을 학습하고, 다른 교과 내용을 작품에 적용하는 교과 융합 학습이 도움이 됩니다.

무엇을 묻나 · 시에서의 시간·공간의 기능과 시적 장치의 역할을 설명한 (가)의 관점을, (나)·(다) 두 작품에 적용해 시간·공간을 형상화하는 양상을 각각의 시어로 구체화합니다.

교수·학습 주안점 · 기존 해석에 의존하기보다 다양한 관점에서 주체적으로 감상합니다. 작품을 해석할 때 내·외적 근거를 찾아 가치와 의미를 설득력 있게 제시하고, 작품에 대한 다양한 의견을 접하며 문학 수용의 안목을 넓힙니다.

핵심 정리

국어 예시문항은 ‘지식 암기’가 아니라 지문·자료를 연결해 근거를 회수하고, 새로운 맥락에 적용·비판하는 능력을 묻습니다. 7문항 모두 둘 이상의 성취기준이 통합되어 있어, 화법·언어·독서·작문·문학을 따로 보지 말고 ‘읽고 쓰는 통합 능력’으로 훈련해야 합니다.

6. TIME MANAGEMENT

45문항 80분 실전 운영

2028 국어는 선택과목이 없어졌지만 80분 운영의 압박은 그대로입니다. 영역별 목표 시간을 정하고, 막힌 문항의 보류 기준을 미리 정해야 합니다.

구간권장 시간목표주의점
화법과 언어15~18분담화 상황과 언어 자료형을 안정적으로 처리쉬운 듯 보여도 자료 조건과 문법 기능을 표시한다.

8. LEVEL STRATEGY

등급별 전략

국어는 등급별로 필요한 훈련이 다릅니다. 상위권은 함정 제거, 중위권은 절차 고정, 하위권은 어휘·개념·기초 기출이 우선입니다.

1~2등급: 고난도 자료형과 오답 선지 함정 관리
  • 맞힌 문제 중 오래 걸린 문항을 우선 복기한다.
  • 오답 선지의 틀린 단어와 함정 유형을 기록한다.
  • 독서와 작문에서 추가 자료의 기능을 빠르게 분류한다.
  • 문학은 보기 자료의 관점을 작품 구절과 직접 연결한다.
  • 화법과 언어는 담화 맥락과 문법 요소 기능을 함께 본다.
3~4등급: 감으로 푸는 습관 교정
  • 모든 선지 옆에 근거 위치를 적는다.
  • 문단 역할은 완벽한 요약보다 한 단어 표시부터 시작한다.
  • 화법과 언어는 화자·청자·목적·어휘/문법 요소를 표로 정리한다.
  • 문학은 상황·정서·태도·근거 4칸 표를 고정한다.
주차목표행동
1주차약점 진단최근 기출 1회분을 풀고 과목별 오답 원인을 기록한다.
2주차독서와 작문하루 1지문 문단 역할+자료 기능+작문 조건 분석
3주차문학하루 1세트 보기 관점 적용과 정서 과장 선지 제거
4주차화법과 언어·실전자료형 문항과 80분 실전 2회 복기
5등급 이하: 필수 어휘·개념어와 기출 1회독
  • 어휘·개념어를 먼저 정리한다.
  • 지문은 시간 제한 없이 읽고 문단별 한 문장 요약을 한다.
  • 문학은 화자·상황·정서·태도부터 잡는다.
  • 기출은 연도별 전체 풀이보다 과목별 기본 문항부터 시작한다.
기간목표행동
