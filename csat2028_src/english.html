2028 수능 영어
진짜 공부법

2028학년도 수능 영어는 현행과 같이 영어Ⅰ·영어Ⅱ를 바탕으로 45문항, 70분, 듣기 17문항 포함, 절대평가로 운영됩니다. 이 페이지는 학생이 바로 실행할 수 있도록 단어·구문·논리·듣기·EBS 간접연계·70분 운영을 하나의 수능 전용 전략으로 정리했습니다.

제작자: 충청남도진로융합교육원 교육연구사 정재연

핵심 메시지

수능 영어는 절대평가이지만 “대충 90점”을 노리는 시험이 아닙니다. 듣기와 쉬운 독해를 안정적으로 확보하고, 빈칸·순서·삽입에서 글의 논리 흐름을 근거로 판단해야 1등급이 유지됩니다.

단어구문문단 기능주제문패러프레이징70분 운영

  • 체크리스트, 메모, 타이머, 복기표는 브라우저에 저장됩니다.

1. 2028 STRUCTURE

2028 수능 영어 구조 한눈에 보기

2028 수능에서 영어는 국어·수학·탐구처럼 선택과목 폐지의 직접 영향을 받지 않습니다. 핵심은 현행 영어 수능의 논리 독해와 듣기 안정성을 그대로 더 정교하게 준비하는 것입니다.

항목2028 수능 영어학생이 알아야 할 의미
출제 범위영어Ⅰ, 영어Ⅱ를 바탕으로 다양한 소재의 지문과 자료 활용교과서 문장 암기가 아니라, 고등 영어의 읽기·듣기·어휘·구문·담화 이해 능력이 핵심이다.
문항 수45문항듣기 17문항 + 읽기·간접쓰기 중심 독해 28문항을 70분 안에 처리해야 한다.
듣기17문항 포함듣기는 1등급의 안전장치다. 1문항이라도 틀리면 독해 고난도 부담이 커진다.
시험 시간70분듣기 중 독해 병행 여부는 학생별로 다르지만, 기본 원칙은 듣기 실수 0개다.
문항 유형5지선다형, 2·3점 배점3점 문항은 보통 논리 흐름과 선지 패러프레이징에서 변별된다.
성적 표기절대평가 등급표준점수·백분위가 아니라 등급이 제공된다. 목표 점수대별 전략이 달라야 한다.
EBS 연계문항 수 기준 50%, 간접 방식지문 암기가 아니라 소재·주제·상황·요지·표현의 재구성을 대비해야 한다.
중요 · 영어는 예시문항이 별도로 발표되지 않았습니다
2028 예시문항이 공개된 과목은 국어·수학·통합사회·통합과학입니다. 영어는 절대평가로 현행 체제(영어Ⅰ·Ⅱ, 45문항 70분, 듣기 17문항, EBS 50% 간접연계)가 그대로 유지되므로 별도 예시문항이 없습니다. 따라서 이 페이지의 유형·번호 운영은 현행 평가원 영어 수능의 출제 기조와 공식 체제에 근거한 훈련용 전략이며, 세부 배열은 추후 시행계획과 모의평가에서 확정적으로 확인하세요.

절대평가 영어의 등급 전략

목표원점수 기준전략
1등급90점 이상듣기 만점 + 쉬운 독해 무실수 + 빈칸·순서·삽입 중 2~3문항 이내 손실
2등급80점 이상듣기 안정 + 쉬운 독해 확보 + 고난도 유형 일부 선택적 공략
3등급70점 이상단어·구문 기반으로 주제·제목·내용일치·장문 쉬운 문항 우선 확보
4등급 이하69점 이하듣기와 문장 단위 해석을 먼저 세워 기본 점수를 만든다.

영어Ⅰ·영어Ⅱ 기반 학습의 의미

영어Ⅰ·영어Ⅱ는 수능 영어의 소재와 읽기·듣기 활동 기반입니다. 시험에서는 교과서 특정 본문보다, 다양한 소재의 글을 읽으며 중심 내용, 세부 정보, 함축 의미, 논리 전개, 어휘·구문을 처리하는 능력이 드러납니다.

교과 기반 학습의 방향
영어Ⅰ·영어Ⅱ 지문 읽기
→ 핵심 어휘와 구문 분석
→ 문단 기능 파악
→ 주제문과 근거 찾기
→ 선지 표현과 패러프레이징 비교

3. ESSENCE

수능 영어의 본질: 단어·구문·논리

수능 영어는 문장을 한국어로 바꾸는 시험이 아니라, 글의 논리 흐름을 읽고 정답 선지가 지문의 핵심을 어떻게 바꾸어 말했는지 판단하는 시험입니다.

단어

단어는 뜻 하나가 아니라 문맥 속 기능입니다. 품사, 다의어, 유의어, 반의어, 자주 결합하는 표현까지 알아야 선지 패러프레이징이 됩니다.

단어 학습 = 뜻 + 품사 + 문맥 방향 + 유의어/반의어 + 예문

구문

구문은 긴 문장을 핵심 구조로 줄이는 능력입니다. 주어·동사·목적어·보어를 먼저 찾고, 수식어는 괄호로 분리해야 합니다.

구문 학습 = 핵심문장 찾기 + 수식어 제거 + 절/구 기능 확인

논리

논리는 고난도 유형의 핵심입니다. 문장이 주제, 이유, 예시, 반박, 결론 중 어떤 역할인지 판단해야 빈칸·순서·삽입이 풀립니다.

논리 학습 = 문장 기능 + 연결어 + 반복 핵심어 + 패러프레이징

수능 영어에서 글을 읽는 순서

제목·첫 문장반복 핵심어연결어주제문문장 기능선지 변환
읽는 대상확인 질문표시법
첫 문장화제인가, 문제 제기인가, 통념인가?Topic / Problem / Common belief
연결어글의 방향이 유지되는가, 전환되는가?however, therefore, for example, in other words 표시
예시무엇을 설명하기 위한 예시인가?Example → principle 화살표
마지막 문장결론인가, 한계인가, 전망인가?Conclusion / Limitation / Implication
선지지문의 핵심을 과장·축소·반대로 바꾸었는가?틀린 단어 표시
4. VOCABULARY & SYNTAX

단어와 구문: 점수의 하한선을 만든다

단어와 구문이 약하면 고난도 유형 전략이 작동하지 않습니다. 2028 영어 대비에서도 기본기는 “많이 외우기”가 아니라 “문맥에서 꺼내 쓰기”입니다.

단어 암기 루틴

시점행동목표
아침새 단어 30~50개 1차 암기뜻과 품사 확인
점심뜻 가리고 빠르게 테스트즉시 회상
저녁예문 속 의미 확인문맥상 의미
다음 날전날 단어 누적 테스트망각 방지
주말틀린 단어만 재분류다의어·혼동어 정리
단어장에 반드시 쓸 것
뜻 하나만 쓰지 말고 품사, 예문, 유의어, 반의어, 문맥상 의미, 헷갈리는 단어를 함께 씁니다.

구문 독해 5단계

1. 주어에 밑줄을 긋는다.
2. 동사에 동그라미를 친다.
3. 목적어·보어를 표시한다.
4. 관계사절·분사구문·전치사구 등 수식어를 괄호 처리한다.
5. 핵심 문장을 먼저 해석한 뒤 수식어를 붙인다.
예시
People who are exposed to too much information often find it difficult to make decisions.

핵심 구조: People find it difficult.
수식·보충: who are exposed to too much information / to make decisions

고난도 구문 체크리스트

  • 관계사절이 여러 개 겹친 문장
  • 분사구문과 삽입구가 있는 문장
  • not A but B 구조
  • as가 여러 의미로 쓰인 문장
  • 가주어·진주어 it-that 구조
  • 가정법과 조건문
  • 비교급·최상급 구문
  • 명사절·형용사절·부사절 혼합
  • 수동태와 능동태가 섞인 문장
5. LOGIC

논리 독해와 패러프레이징

정답 선지는 지문의 문장을 그대로 복사하지 않습니다. 같은 의미를 다른 말로 바꾸는 방식을 읽어야 합니다.

지문 표현선지 표현판단 포인트

6. ITEM TYPES

유형별 출제 코드와 첫 행동

수능 영어 유형은 각각 묻는 능력이 다릅니다. 유형별 첫 행동을 고정하면 실전에서 흔들림이 줄어듭니다.

주제·요지·제목

글 전체의 중심 내용을 압축하는 유형입니다. 예시와 세부 정보를 주제로 착각하지 않는 것이 핵심입니다.

첫 행동
1. 첫 문장과 마지막 문장 확인
2. 반복 핵심어 표시
3. 예시가 설명하는 일반 원리 찾기
4. 선지가 너무 넓거나 좁은지 확인

내용일치·도표·실용문

정확성과 속도를 동시에 요구합니다. 지문 전체를 깊이 해석하기보다 조건·수치·대상·예외를 빠르게 대조합니다.

첫 행동
1. 선지의 고유명사·수치·조건 표시
2. 지문에서 해당 정보 위치 찾기
3. 단위·시간·대상·예외 확인
4. 근거가 직접 있으면 판단

어법

수능 어법은 핵심 문법의 실제 적용입니다. 주어와 동사, 능동·수동, 병렬, 관계사 구조를 확인합니다.

첫 행동
1. 주어와 동사 찾기
2. 수식어 걷어내기
3. 수일치 확인
4. 능동·수동 판단
5. 병렬·관계사 구조 확인

어휘

어휘는 뜻 암기가 아니라 문맥의 방향 판단입니다. 긍정·부정 흐름, 대조, 원인·결과를 기준으로 선택합니다.

첫 행동
1. 해당 문장의 긍정/부정 방향 확인
2. 앞뒤 문장 논리 확인
3. 대조 연결어 확인
4. 반의어가 자연스러운지 검토

빈칸 추론

빈칸은 글의 핵심 논리를 복원하는 유형입니다. 선지를 보기 전에 빈칸 내용을 한국어로 먼저 예측합니다.

첫 행동
1. 빈칸 문장의 역할 확인
2. 앞뒤 연결어 확인
3. 글 전체 주제 파악
4. 한국어로 먼저 예측
5. 예측과 가장 가까운 선지 선택
6. 과장·지엽 선지 제거

순서 맞추기

순서는 문장 간 연결 고리를 묻습니다. 대명사, 지시어, 접속사, 일반 진술과 구체 예시의 순서를 근거로 삼습니다.

강력한 단서
this / that / it → 앞에 대상 필요
however → 앞 문장과 대조
therefore → 앞에 이유 필요
for example → 앞에 일반 진술 필요
another → 앞에 첫 항목 필요

문장 삽입

삽입은 앞 문장과 뒤 문장이 모두 자연스럽게 이어지는 위치를 찾는 유형입니다. 앞만 맞고 뒤가 끊기면 오답입니다.

첫 행동
1. 삽입문 핵심어 표시
2. 대명사·지시어 확인
3. 삽입문이 앞 문장과 맺어야 할 관계 판단
4. 후보 위치의 앞뒤 문장을 모두 읽기
5. 3문장 연결 검증

무관한 문장

지문에 나온 단어가 있어도 주제 흐름에서 벗어나면 무관합니다. 문장의 소재가 아니라 기능을 봐야 합니다.

첫 행동
1. 각 문장의 역할을 한 단어로 표시
2. 반복 핵심어와 논리 흐름 확인
3. 갑자기 다른 관점·대상·초점이 들어오는 문장 찾기
4. 앞뒤 연결이 복원되는지 확인

요약문

요약문은 글 전체를 두 핵심어로 압축하는 유형입니다. 빈칸 단어는 보통 핵심 개념과 결론 방향을 담습니다.

첫 행동
1. 글의 주제와 결론 찾기
2. 반복 핵심어 2개 표시
3. 요약문의 문장 구조 확인
4. 원문과 의미 방향 일치 확인

장문 독해

장문은 정보량이 많지만 문제는 보통 순서, 주제, 내용일치, 지칭 대상 중심입니다. 문단별 기능을 잡으면 빠르게 풀 수 있습니다.

첫 행동
1. 각 문단 중심 사건 또는 주장 표시
2. 인물·대상·시점 변화 확인
3. 문제 선지의 정보 위치 찾기
4. 세부 정보는 필요한 부분만 재독

9. 70-MINUTE OPERATION

70분 실전 운영 전략

수능 영어의 실전 운영은 듣기를 지키고, 쉬운 문제를 빠르게 확보하고, 고난도 문항에 들어갈 시간을 남기는 방식으로 설계해야 합니다.

기본 시간 배분

구간권장 시간행동
듣기약 25분듣기 만점 우선. 듣기 안정권만 쉬운 독해 일부 병행.
쉬운 독해10~12분목적·심경·주제·제목·도표·내용일치·실용문 빠르게 확보.

고난도18~22분빈칸, 순서, 삽입, 무관한 문장 집중.
장문·검토8~10분장문 정보 대조, 표시 문제 재검토, 마킹 확인.

11. LEVEL STRATEGY

등급별 추천 전략

절대평가 영어는 현재 등급에 따라 공부의 우선순위가 완전히 다릅니다. 자신의 목표 등급에 맞는 문항을 먼저 확보해야 합니다.

1등급 목표·유지

목표는 “공부량을 많이 늘리기”가 아니라 감각 유지와 고난도 손실 최소화입니다.

  • 듣기 실수 0개를 유지한다.
  • 주 2~3회 고난도 독해를 푼다.
  • 빈칸·순서·삽입 오답만 따로 복기한다.
  • 선지의 과장·지엽·반대 표현을 표시한다.
  • 실모 후 오래 걸린 문항을 줄인다.

2~3등급

핵심은 빈칸·순서·삽입 중 가장 약한 유형을 집중적으로 줄이는 것입니다.

  • 듣기 만점부터 고정한다.
  • 쉬운 독해에서 실수를 없앤다.
  • 빈칸은 한국어 예측문을 먼저 쓴다.
  • 순서·삽입은 지시어와 연결어 근거를 표시한다.
  • 70분 실모로 시간 부족 유형을 찾는다.

4등급 이하

고난도보다 단어·구문·듣기·쉬운 독해를 먼저 세워야 합니다.

  • 하루 단어 30개, 누적 복습을 시작한다.
  • 문장마다 주어·동사를 표시한다.
  • 듣기 대본 복습과 따라 읽기를 한다.
  • 목적·심경·주제·제목·내용일치부터 맞힌다.
  • 빈칸·순서·삽입은 기본 문항만 선별한다.
