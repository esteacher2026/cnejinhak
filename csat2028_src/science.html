2028학년도 수능 과학탐구는 선택 과학탐구 과목이 아니라 모든 사회·과학탐구 응시자가 통합과학을 공통으로 응시하는 구조입니다. 핵심은 물리·화학·생명과학·지구과학을 따로 외우는 것이 아니라, 개념을 연결하고 탐구 자료를 근거로 판단하는 능력입니다.

2028 수능 과학탐구 구조 한눈에 보기

기존 선택 과탐식 접근2028 통합과학식 접근학생의 행동 변화
물리·화학·생명과학·지구과학 중 1~2과목을 깊게 선택통합과학1·2 전체에서 공통 개념과 탐구 과정을 함께 평가개념을 과목별로만 정리하지 말고, 현상·자료·탐구 행동과 연결한다.
과목별 고난도 계산·킬러 유형 반복교육과정 수준의 기본 개념을 다양한 탐구 상황에 적용복잡한 계산보다 조건, 변인, 그래프, 표의 의미를 먼저 읽는다.
단원 암기와 유형풀이 중심내용 영역 + 행동 영역을 동시에 평가문항마다 “무슨 개념?”과 “무슨 행동?”을 함께 표시한다.
자료 해석은 과목별 부가 요소자료 변환·해석, 결론 도출, 의사소통이 핵심 행동 영역표·그래프·그림·실험 과정을 정답 근거로 읽는 훈련을 한다.
실전 감각
25문항 40분은 짧습니다. 쉬운 개념 문항은 빠르게 확보하고, 탐구 설계·자료 해석·결론 도출 문항은 축·단위·변인·근거를 표시하는 절차로 풀어야 합니다.

03 · Essence

통합과학의 본질: 개념을 연결하고, 탐구 상황에서 판단하라

통합과학은 물리·화학·생명과학·지구과학의 단순한 합이 아닙니다. 하나의 자연 현상이나 기술·사회 문제를 여러 과학 개념으로 해석하고, 자료를 근거로 결론을 만드는 과목입니다.

수능 통합과학에서 ‘개념을 안다’는 것

  • 용어의 정의를 말할 수 있다.
  • 그 개념이 적용되는 조건과 예외를 안다.
  • 그림, 표, 그래프, 실험 결과에서 개념의 증거를 찾을 수 있다.
  • 비슷한 개념과 구분할 수 있다.
  • 일상생활·자연환경·미래 사회 사례에 적용할 수 있다.

통합과학 문항의 기본 해석 순서

1. 질문 먼저 읽기: 무엇을 구하라고 하는가?
2. 내용 영역 표시: 물질, 시스템, 변화, 환경, 미래 사회 중 무엇인가?
3. 행동 영역 표시: 이해, 적용, 탐구 설계, 자료 해석, 결론 도출 중 무엇인가?
4. 자료 읽기: 제목, 축, 단위, 범례, 조건, 변인 표시
5. 관계 만들기: 표·화살표·그림 중 하나로 정리
6. 선지 판단: 자료 근거가 있는 것과 없는 것을 구분
04 · Content Areas

출제 범위와 6개 내용 영역

2028 수능 통합과학은 통합과학1과 통합과학2를 기반으로 합니다. 6개 영역은 따로 떨어져 있지 않고, 물리·화학·생명과학·지구과학 개념을 연결하는 구조입니다.

통합과학1 과학의 기초

과학 전체의 도구적 언어입니다. 단위, 측정, 어림, 정보와 신호를 제대로 다루어야 자료형 문항에서 흔들리지 않습니다.

내용 요소: 기본량과 단위 / 측정과 어림 / 정보와 신호
첫 행동: 단위, 기준값, 측정값, 오차 가능성 표시

통합과학1 물질과 규칙성

원소 형성, 주기성, 결합, 지각·생명체 구성 물질, 전기적 성질을 연결합니다. 암기보다 “왜 그런 성질이 나타나는가”가 중요합니다.

내용 요소: 원소 형성 / 별의 진화 / 원소의 주기성 / 이온 결합 / 공유 결합 / 지각과 생명체 구성 물질의 규칙성 / 물질의 전기적 성질
첫 행동: 원자 구조, 전자 배치, 결합 방식, 물질의 성질 연결

통합과학1 시스템과 상호작용

지구시스템, 판구조론, 중력장 운동, 운동량·충격량, 생명 시스템, 물질대사, 유전자와 단백질을 시스템 관점으로 봅니다.

내용 요소: 지구시스템의 구성과 상호작용 / 판구조론과 지각 변동 / 중력장 내의 운동 / 충격량과 운동량 / 생명 시스템의 기본 단위 / 물질대사 / 유전자와 단백질
첫 행동: 구성 요소, 상호작용, 에너지·물질·정보 흐름 표시

통합과학2 변화와 다양성

지질시대 변화, 자연선택, 생물다양성, 산화·환원, 산·염기, 중화 반응, 에너지 출입을 “변화 전후”로 읽습니다.

내용 요소: 지질시대의 생물과 화석 / 지질시대 환경 변화와 대멸종 / 자연선택 / 생물다양성 / 산화와 환원 / 산성과 염기성 / 중화 반응 / 물질 변화에서 에너지 출입
첫 행동: 변화 전·후, 원인·결과, 에너지 흡수·방출 표시

통합과학2 환경과 에너지

생태계 평형, 대기·해양 상호작용, 지구온난화, 핵융합, 발전, 에너지 전환과 효율을 자료와 시스템으로 해석합니다.

내용 요소: 생태계 구성 요소 / 생태계 평형 / 대기와 해양의 상호작용 / 온실기체와 지구온난화 / 핵융합 / 발전 / 에너지 전환과 효율
첫 행동: 입력·출력, 순환, 피드백, 에너지 전환 경로 표시

통합과학2 과학과 미래 사회

감염병, 빅데이터·인공지능, 로봇, 과학기술 윤리는 단순 시사 문제가 아니라 과학적 자료 분석과 의사 결정 문제입니다.

내용 요소: 감염병과 병원체 / 인공지능과 과학 탐구 / 로봇 / 과학기술과 윤리
첫 행동: 자료 수집, 변인 관계, 예측, 사회적 의사 결정 기준 표시
05 · Behavior Areas

8개 행동 영역별 풀이법

통합과학은 ‘무엇을 아는가’뿐 아니라 ‘어떤 방식으로 탐구하고 판단하는가’를 평가합니다. 문제를 풀 때는 내용 영역과 함께 행동 영역을 반드시 표시해야 합니다.

행동 영역평가 의미첫 행동오답 방지 포인트
이해교육과정 주요 개념 이해용어·구조·기능을 연결한다.정의만 외우지 말고 예시와 쓰임까지 확인한다.
적용일상생활·자연환경 현상에 개념 적용현상을 개념 언어로 바꾼다.사례의 소재에 끌려가 핵심 조건을 놓치지 않는다.
문제 인식 및 가설 설정자연 현상에서 문제를 인식하고 타당한 가설 설정탐구 목적과 가설의 검증 가능성을 본다.가설이 실험 결과로 검증 가능한지 확인한다.
탐구 설계가설 검증을 위한 탐구 설계와 실험 과정 의미 설명조작·종속·통제 변인을 구분한다.통제 변인을 결과와 무관한 장식처럼 보지 않는다.
탐구 수행 및 자료 수집도구를 활용한 실험 수행과 자료·정보 수집자료 수집 과정과 신뢰도 처리 과정을 확인한다.측정 오차, 편향값, 데이터 변환을 무시하지 않는다.
자료 변환 및 해석자료를 그래프·표·그림으로 나타내고 경향성·규칙성 파악제목, 축, 단위, 편차, 기준값을 표시한다.증가·감소만 보지 말고 비교 대상과 예외를 확인한다.
결론 도출 및 일반화수학적 사고·모형 활용, 자료 분석·평가 후 결론 도출자료에서 직접 도출되는 결론과 예측을 구분한다.상관관계를 인과관계로 과장하지 않는다.
의사소통과학적 주장을 다양한 방법으로 소통하고 의사 결정에 활용주장, 근거, 사례, 의사 결정 기준을 분리한다.과학 개념과 일상 사례가 맞게 연결되는지 확인한다.
행동 영역 표시법
문제 옆에 이해 / 적용 / 가설 / 설계 / 수집 / 해석 / 결론 / 소통 중 하나를 써 보세요. 오답노트도 단원명보다 행동 영역으로 묶으면 약점이 훨씬 빨리 보입니다.

자료형·탐구형 문제 접근법

통합과학에서 점수를 가르는 것은 낯선 자료를 만났을 때의 첫 행동입니다. 문제 유형별로 읽는 순서를 고정하세요.

자료 해석 7단계

1. 제목을 읽는다.
2. 축, 단위, 범례, 기준값을 표시한다.
3. 무엇이 변하고 무엇이 일정한지 찾는다.
4. 비교 대상 A/B를 표시한다.
5. 증가·감소·일정·예외 구간을 표시한다.
6. 자료에서 직접 알 수 있는 것과 추론해야 하는 것을 분리한다.
7. 선지를 보기 전에 자료의 결론을 한 문장으로 말한다.

그래프형

  • x축·y축·단위·편차 기준을 먼저 확인한다.
  • 기울기, 면적, 최대·최소, 변화량을 표시한다.
  • 그래프가 말하는 직접 정보와 추론 정보를 구분한다.

표·자료형

  • 행과 열의 의미를 먼저 적는다.
  • 비율, 질량, 농도, 개수, 시간 단위를 구분한다.
  • 가장 큰 값, 가장 작은 값, 예외값을 표시한다.

실험 설계형

  • 탐구 목적과 가설을 먼저 찾는다.
  • 조작 변인, 종속 변인, 통제 변인을 표로 쓴다.
  • 각 실험 과정이 왜 필요한지 이유를 붙인다.

시스템형

  • 구성 요소와 상호작용을 박스와 화살표로 나타낸다.
  • 물질, 에너지, 정보의 흐름을 구분한다.
  • 한 요소 변화가 다른 요소에 미치는 영향을 추론한다.

생활 적용형

  • 사례의 소재보다 과학 개념의 조건을 먼저 본다.
  • 일상 현상을 과학 용어로 번역한다.
  • 비슷한 사례와 다른 점을 확인한다.

의사소통형

  • 주장, 근거, 사례, 의사 결정 기준을 분리한다.
  • 선지가 과학 개념을 정확히 말하는지 확인한다.
  • 과학적 근거 없는 가치 판단 선지를 경계한다.

09 · 40-Minute Operation

25문항 40분 실전 운영 전략

통합과학은 한 과목 40분 안에 25문항을 풀어야 합니다. 어려운 문항 한두 개에 시간을 과하게 쓰면 쉬운 문항 검토 시간이 사라집니다.

권장 시간 배분

시간목표행동
0~14분1회전: 쉬운 개념·짧은 자료 문항 확보60초 안에 풀이 방향이 보이지 않으면 표시하고 넘긴다.
14~28분2회전: 자료 해석·탐구 설계 문항 해결축·단위·변인·관계표를 만들고 선지별 근거를 확인한다.
28~35분3회전: 남은 고난도·복합 문항 집중정답 후보를 줄이고, 계산보다 조건 해석을 재확인한다.
35~40분검토: 답안·조건·단위·부호 확인찍은 문항보다 풀었던 문항의 단위·방향·선지 표현을 먼저 본다.

문항 보류 기준

  • 첫 60초 동안 내용 영역도 행동 영역도 잡히지 않으면 표시하고 넘긴다.
  • 그래프를 두 번 읽었는데 축·단위가 헷갈리면 선지를 보지 말고 자료부터 다시 정리한다.
  • 실험 문항에서 변인이 정리되지 않으면 바로 계산하지 않는다.
  • 고난도 한 문항보다 쉬운 문항 3개의 검토 시간이 더 중요하다.
10 · Level Strategy

수준별 추천 전략

통합과학은 상대평가 영역이므로 목표 등급에 따라 우선순위가 달라져야 합니다.

1~2등급 목표

  • 예시문항 8행동 영역을 모두 오답노트화한다.
  • 맞은 문항 중 오래 걸린 문항을 별도로 복기한다.
  • 자료 해석에서 직접 정보와 추론 정보를 분리한다.
  • 실모 후 2.5점 문항의 시간 과소비 원인을 기록한다.
  • 과학과 미래 사회, 환경과 에너지처럼 자료형이 강한 단원을 놓치지 않는다.

3~4등급 목표

  • 6개 내용 영역의 기본 개념표를 먼저 완성한다.
  • 그래프·표·실험 문항의 첫 행동을 고정한다.
  • 탐구 설계 문항에서 변인표를 매번 작성한다.
  • 쉬운 개념 문항과 중간 자료형 문항을 안정적으로 확보한다.
  • 고난도 문항보다 “틀리면 안 되는 문항”을 줄인다.
중위권 4주 루틴
1주차: 내용 영역 개념 구멍 찾기
2주차: 자료 해석 7단계 훈련
3주차: 예시문항 행동 영역별 분석
4주차: 25문항 40분 실전 운영

5등급 이하 목표

  • 용어, 그림, 표를 먼저 읽을 수 있게 만든다.
  • 교과서 핵심 탐구 활동을 목적·변인·결론으로 정리한다.
  • 개념 하나당 쉬운 사례 2개를 붙인다.
  • 자료형 문항은 제목·축·단위만이라도 정확히 표시한다.
  • 실전에서는 쉬운 문항을 놓치지 않는 것이 1차 목표다.
